# DSA

This folder contains all my Data Structures and Algorithms practice questions as part of my interview preparation journey.

Each file here represents problems I’ve worked on, including different approaches, optimizations, and clean implementations.

Topics covered include:
- Arrays and Strings
- Hashing
- Sorting and Searching
- Two Pointers and Sliding Window
- Prefix Sum and Kadane’s Algorithm
- Bit Manipulation (XOR-based logic)
- Stack, Queue, and Monotonic Structures
- Binary Trees and Graphs
- Recursion and Dynamic Programming

I'm continuously updating this as I practice and learn.

Feel free to explore, suggest improvements, or use the code for your own learning.
